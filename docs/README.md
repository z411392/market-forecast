## SSOT 原則

- GitHub Project：Status / Priority / Sprint。
- GitHub Issue：Epic / Story / Task / Spike / Bug 與人類可讀歷史。
- `specs/<issue>-<slug>/spec.md`：Story 特有需求與 AC。
- `plan.md`：方案。
- `progress.md`：durable evidence / 阻塞。
- `docs/`：跨 Story 的產品、領域、架構與治理模型。
